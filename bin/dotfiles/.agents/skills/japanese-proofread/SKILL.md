# Japanese proofreading

Make the smallest changes needed to correct clear errors or tidy the requested presentation. Preserve the author's meaning, level of formality, terminology, emphasis, and paragraph structure. Do not add interpretations, claims, examples, or missing context.

Keep the author's punctuation and notation choices, including `，．`, `、。`, and any mixture of them. Do not silently standardize punctuation, character width, spelling variants, or sentence endings. Change one of these only when the user explicitly asks or it is necessary to correct an unmistakable error.

If a passage is unclear and its intended meaning cannot be determined, point it out and ask for clarification instead of guessing. When you change wording to improve clarity or convey the intended meaning, give a specific reason for each such change. Keep those reasons separate from the revised text so the result can be copied as written. Purely mechanical corrections need no individual explanation unless the user asks for one.

Follow any explicit editing scope or style instructions from the user over these defaults.
